# Промпты для каждого этапа (ЧАСТЬ 8)

Отправляй по одному, когда предыдущий этап проверен. `<Имя>` — имя персонажа.

---

## 1. Концепция
```
Этап 1 — концепция. Ничего в Blender пока не меняй.
Опиши: пропорции (рост, сколько «голов», ширина плеч/таза), анатомию и её отличия от человека,
3 главные формы силуэта, особенности головы, список деталей по приоритету,
список объектов с именами и материалов. Предложи 2 варианта силуэта, я выберу.
```

## 2. Blockout
```
Этап 2 — Blockout в коллекции 01_Blockout. Только крупные формы, без деталей.
Голова, торс, таз, руки, кисти (варежкой), ноги, стопы, дополнительные части существа.
Используй Skin-модификатор или метаболлы для органики, симметрию по X (Mirror).
Держи масштаб относительно REF_Human_1.80m. Покажи скриншоты спереди/сбоку/3-4,
затем сравни силуэт с концепцией и перечисли, что поправить. Сохрани <Имя>_Blockout.blend.
```

## 3. High Poly
```
Этап 3 — High Poly. Скопируй блокаут в 02_HighPoly (оригинал не трогай).
Объедини части, Voxel Remesh (начни с 0.02 м, сообщи полигонаж перед уменьшением),
добавь Multires и сделай процедурную детализацию: мышечные массы, складки, рельеф коры
(Displace + процедурная текстура), пальцы.
Честно скажи, какие детали (лицо, мелкая анатомия) лучше доделать вручную кистями
Sculpt Mode, и дай мне список кистей и порядок работы. Сохрани <Имя>_HighPoly.blend.
```

## 4. Retopology
```
Этап 4 — Retopology в 03_LowPoly. Цель: ≤ 40 000 треугольников (NPC) / ≤ 15 000 (мобильный).
Вариант А (авто): Quadriflow Remesh + Shrinkwrap на high poly, затем проверка.
Вариант Б (ручной): подготовь сцену для ручной ретопологии (snap to face, Shrinkwrap,
In Front), и объясни, где нужны кольца рёбер (глаза, рот, плечи, локти, колени, пальцы).
После — запусти game_asset_checker.py и покажи отчёт. Сохрани <Имя>_LowPoly.blend.
```

## 5. UV
```
Этап 5 — UV low poly. Расставь швы в незаметных местах (внутренняя сторона рук и ног,
под волосами, спина), Unwrap, Pack Islands с отступом 4 px для 2048,
одинаковая плотность текселя (Average Islands Scale). Глаза/зубы/когти — отдельные острова
или отдельный UDIM. Покажи UV в виде сетки с checker-текстурой. Проверь отчётом checker.
```

## 6. Baking
```
Этап 6 — запекание с high poly на low poly в Cycles. Разрешение 2048.
Карты: Normal (OpenGL для Unity/Godot, DirectX — переверни G для Unreal), AO.
Extrusion/Cage подбери так, чтобы не было артефактов; покажи результат и проблемные зоны.
Сохрани PNG в Textures/Normal и Textures/AO.
```

## 7. Texturing
```
Этап 7 — материалы и текстуры. Отдельные материалы: кожа/кора, мох, глаза, когти/рога.
Используй запечённые Normal/AO, процедурные вариации цвета (не однотонные),
Poly Haven текстуры, если подходят (проверь лицензию CC0). Запеки Base Color и Roughness
в Textures/BaseColor и Textures/Roughness, чтобы материал работал в движке без нод Blender.
```

## 8. Rigging
```
Этап 8 — риггинг через Rigify. Добавь Human (Meta-Rig), подгони кости под модель
(для существа — добавь кости для рогов/хвоста/доп. частей), Generate Rig,
привяжи меш (Automatic Weights). Покажи позы: руки вверх, присед, поворот корпуса,
наклон головы — проверь плечи, локти, колени. Перечисли зоны, где нужен ручной Weight Paint.
```

## 9. Проверка и экспорт
```
Этап 9 — финальная проверка и экспорт. Примени трансформации (rotation/scale),
положи финальный меш и скелет в 07_Export, запусти game_asset_checker.py.
Если FAIL нет — выполни export_for_engine.py с пресетом <unity|unreal|godot|generic>.
Сохрани <Имя>_Final.blend. Дай итоговую таблицу: полигонаж, материалы, текстуры,
кости, файлы экспорта.
```

- «Покажи сцену с 4 сторон и в режиме wireframe».
- «Проверь модель скриптом game_asset_checker.py и объясни каждый WARN».
- «Сохрани версию перед следующим шагом».
- «Откати последнее изменение» (Claude выполнит `bpy.ops.ed.undo()` или восстановит копию).
