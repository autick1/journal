# Настройки под твоё железо

Ответы на три вопроса из конца гайда определяют настройки ниже. Найди свою строку.

## Видеокарта → рендер и запекание

| Видеокарта | Cycles: Preferences → System | Запекание | Примечание |
|---|---|---|---|
| NVIDIA RTX (20xx–50xx) | **OptiX** | GPU, 4K ок (8+ ГБ VRAM) | Лучший вариант, включи OptiX Denoiser |
| NVIDIA GTX (10xx/16xx) | **CUDA** | GPU, 2K; 4K — если 6+ ГБ VRAM | OptiX на GTX медленнее CUDA |
| AMD Radeon RX 6000/7000/9000 | **HIP** | GPU, 2K–4K | Обнови драйвер Adrenalin |
| Intel Arc | **oneAPI** | GPU, 2K | |
| Встроенная графика | CPU | CPU, 2K максимум | Eevee для превью, Cycles только для запекания |

Eevee работает на любой из перечисленных — для проверочных рендеров его достаточно.

## Оперативная память → скульптинг и ремеш

| RAM | Комфортный предел скульпта | Voxel Remesh (рост 2 м) | Multires | Текстуры |
|---|---|---|---|---|
| 16 ГБ | 2–4 млн полигонов | не меньше 0.01 м | до 4 уровней | 2K, запекание по одной карте |
| 32 ГБ | 8–10 млн | 0.005 м | до 5 уровней | 2K–4K |
| 64 ГБ | 20+ млн | 0.003 м | 6 уровней | 4K, UDIM |

Правило: перед ремешем Claude должен назвать ожидаемый полигонаж. Если он выше предела из таблицы — сначала разделить модель на части.

На 16 ГБ: закрывай браузер во время скульпта, в Preferences → System поставь Undo Steps = 32.

## Windows 10 / 11

Скрипты работают на обеих. Разница:
- Windows 10: если нет `winget`, установи «App Installer» из Microsoft Store.
- Windows 11: `winget` уже есть.
- На обеих: в «Параметры → Система → Дисплей → Графика» добавь `blender.exe` и выбери «Высокая производительность» (важно для ноутбуков с двумя видеокартами).

## Hunyuan3D / локальная AI-генерация

- Веб-версия (3d.hunyuan.tencent.com) и генерация через MCP for Blender работают на любом ПК — считает сервер.
- Локальный запуск Hunyuan3D требует NVIDIA с большим объёмом VRAM (ориентир — 16+ ГБ для формы с текстурой). Проверь актуальные требования в README проекта. На GTX и AMD — используй веб-версию.

Напиши Claude свою видеокарту, RAM и версию Windows — он подставит значения из этих таблиц в настройки сцены.
