# Bellhop (Tripo STL): экспериментальный пайплайн, не доведён

`texture_tripo.py` текстурирует STL из Tripo, у которого нет ни UV, ни цветов, ни целостной сетки
(«суп» из примерно 25 тыс. несвязанных кусков). Что в нём есть: ремонт сетки (Solidify, вокселизация,
Shrinkwrap), low-poly с UV через xatlas, разметка областей и запекание PBR-карт.

**Статус: работа остановлена** после перехода на модель из Meshy (`../BellhopMeshy`), у которой уже есть
UV и чистая сетка. Нерешённые проблемы: после Decimate low-poly местами складывается внутрь себя,
из-за этого в AO и normal map остаются тёмные пятна. Для таких исходников надёжнее сразу
генерировать модель в GLB с текстурами.
